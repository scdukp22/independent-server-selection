## 第一步：机房位置比价格更值得先定

服务器离客户越近，首字节时间和页面加载越稳。这是选独立站服务器的第一优先级，比每月省几美元重要得多。

面向美国客户，选美国西部或东部节点；面向欧洲，法兰克福一带更合适；面向东南亚和中国大陆，中国香港和新加坡延迟更低。多机房服务商的价值就在这里：HawkHost 的机房包括洛杉矶、达拉斯、新加坡、纽约、加拿大、荷兰和香港，SiteGround 也有欧洲、美国、亚洲多个机房可选，本质是让你按客户位置挑，避免所有客户挤在一条线路上。

大陆节点要单独判断。客户主要在海外，用海外节点就够了，不必为了"国内打开快"去备案；只有确实要经营大陆市场、需要大陆访问速度时，才值得走备案流程。

## 第二步：主机类型跟着建站系统走

用 Shopify、Wix、Squarespace 这类 SaaS 建站，主机包含在月费里，不需要单独买服务器；只有用 WordPress 自建，才需要在这三类主机里做选择。

共享虚拟主机便宜、有面板、几乎不用运维，限制是共享 IP 和 CPU 配额。SiteGround、HawkHost、Hostinger 的虚拟主机都属于这一类，适合展示型站点和内容站。

云服务器独享资源、可升降配，环境要自己装或用应用镜像。WooCommerce 商城和流量上升期的站点更适合这一类。

托管型 WordPress 主机和托管云主机（Kinsta、WP Engine、Cloudways 这类）价格更高，换来的是专业 WordPress 支持和省心的运维。

这里有一条容易忽略的分界线：用 WordPress 加 WooCommerce 做在线零售，不建议用共享虚拟主机。WooCommerce 插件本身吃资源，支付网关通常还需要独立 IP，虚拟主机的共享 IP 配不了；单独买独立 IP 之后，成本又接近云 VPS，不如直接上云服务器。这个问题在展示型站点上不存在，但做 B2C 商城绕不开。

## 独立站服务器常见问题

### 2核2G 的服务器够跑独立站吗？

展示型 WordPress 站点、日访客几百到一千，2核2G 够用；WooCommerce 商城建议 2核4G 起步，插件和结账流程更吃内存。

### 海外服务器需要备案吗？

不需要。只有中国大陆地域的服务器需要 ICP 备案，中国香港、新加坡、硅谷等海外地域免备案。

### 轻量应用服务器和云服务器 CVM 有什么区别？

轻量是套餐制，固定带宽加月流量包，带应用镜像，开通快、价格低；CVM 配置自由，可随时升降配，适合业务增长快、需要灵活调整的站点。

### 月流量包用完了怎么办？

轻量应用服务器的月流量包超出后会计费或限速，具体规则以下单页的套餐说明为准。流量波动大的站点，选 CVM 按带宽计费更可控。
